# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TEOS Neurona Nexus, **please do not open a public GitHub issue**. Instead, report it privately to:

**Email:** teos.neurona@proton.me

I will respond within 48 hours and coordinate a fix and disclosure timeline.

## Supported Versions

Only the latest commit on the `main` branch is actively maintained.

## Scope

This project runs on a local network (`127.0.0.1`) and is designed for a single-user, self-hosted environment. Exposing the dashboard to the public internet without additional authentication is **not recommended**.

Thank you for helping keep TEOS Neurona Nexus safe.
